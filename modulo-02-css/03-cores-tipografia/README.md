# Exercício 03 — Cores e tipografia

**Objetivo:** trabalhar paletas de cores e propriedades de texto.

**Enunciado:**
Estilize uma página de "cartão de visita digital" com nome, cargo e uma frase de efeito, usando uma paleta de cores coerente.

**Requisitos técnicos:**
- Defina cores usando pelo menos dois formatos diferentes (ex.: `#hex` e `rgb()`)
- Use `font-family`, `font-size`, `font-weight` e `line-height`
- Importe uma fonte do Google Fonts (via `<link>` no HTML)

**Arquivos esperados:**
```
03-cores-tipografia/
├── index.html
└── style.css
```

**Critérios de avaliação:**
- [ ] Paleta de cores aplicada de forma consistente
- [ ] Fonte externa carregando corretamente
- [ ] Boa legibilidade (contraste e espaçamento de linha adequados)
