# Exercício 01 — Seletores e propriedades básicas

**Objetivo:** entender os diferentes tipos de seletores CSS e como vinculá-los ao HTML.

**Enunciado:**
Reaproveite o HTML do exercício de listas (módulo 01) e crie um `style.css` separado, vinculado via `<link>`.

**Requisitos técnicos:**
- Seletor de elemento (ex.: `p { ... }`)
- Seletor de classe (`.destaque`)
- Seletor de ID (`#titulo-principal`)
- Seletor descendente (ex.: `ul li`)

**Arquivos esperados:**
```
01-seletores-propriedades/
├── index.html
└── style.css
```

**Critérios de avaliação:**
- [ ] CSS em arquivo externo, vinculado corretamente
- [ ] Uso correto dos 4 tipos de seletores pedidos
- [ ] Nenhum estilo inline (`style="..."`) usado
