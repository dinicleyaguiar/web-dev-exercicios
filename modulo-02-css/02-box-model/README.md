# Exercício 02 — Box model

**Objetivo:** compreender margin, border, padding e content.

**Enunciado:**
Crie 3 `<div>` com textos diferentes, simulando "caixas de aviso" (ex.: sucesso, aviso, erro), cada uma com cores e espaçamentos distintos.

**Requisitos técnicos:**
- Uso de `margin`, `padding` e `border` em cada caixa
- Uso de `box-sizing: border-box` no CSS
- Definição de `width` fixo para as caixas

**Arquivos esperados:**
```
02-box-model/
├── index.html
└── style.css
```

**Critérios de avaliação:**
- [ ] As três propriedades do box model aplicadas corretamente
- [ ] `box-sizing: border-box` utilizado
- [ ] Visual consistente entre as três caixas
