# Exercício 04 — Flexbox: galeria de cards

**Objetivo:** aplicar flexbox para criar um layout de cards responsivo.

**Enunciado:**
Crie uma "galeria de projetos" com pelo menos 4 cards (título, imagem e descrição curta), organizados lado a lado com flexbox e que quebrem linha automaticamente em telas menores.

**Requisitos técnicos:**
- `display: flex` no container
- `flex-wrap: wrap`
- `justify-content` e `align-items` configurados
- `gap` entre os cards

**Arquivos esperados:**
```
04-flexbox-cards/
├── index.html
└── style.css
```

**Critérios de avaliação:**
- [ ] Cards alinhados corretamente com flexbox
- [ ] Quebra de linha funcionando (`flex-wrap`)
- [ ] Espaçamento consistente (`gap`)
