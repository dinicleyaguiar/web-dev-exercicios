# 🌐 Exercícios de Programação Web — Turma Iniciante

Repositório de exercícios práticos para a disciplina de Programação Web, organizado por módulos progressivos: **HTML → CSS → JavaScript**, finalizando com um projeto integrador.

## 📚 Estrutura do repositório

```
web-dev-exercicios/
├── modulo-01-html/          # Estrutura e semântica HTML
├── modulo-02-css/           # Estilização e layout
├── modulo-03-javascript/    # Lógica e interatividade
└── projeto-final/           # Projeto integrador (HTML + CSS + JS)
```

Cada exercício possui sua própria pasta com um `README.md` contendo:
- **Objetivo** de aprendizagem
- **Enunciado** do exercício
- **Requisitos técnicos**
- **Critérios de avaliação** (checklist)

## 🚀 Como usar (fluxo recomendado para o GitHub)

1. Faça um **fork** deste repositório (ou crie o seu próprio a partir desta estrutura).
2. Para cada exercício, crie os arquivos pedidos (`index.html`, `style.css`, `script.js`) **dentro da pasta do exercício correspondente**.
3. Faça commits pequenos e descritivos, um por exercício ou por etapa relevante. Exemplos:
   - `git commit -m "feat: estrutura basica do exercicio 01"`
   - `git commit -m "style: box model exercicio 02"`
4. Ao concluir um módulo inteiro, marque com uma tag (opcional):
   ```
   git tag modulo-01-concluido
   git push origin modulo-01-concluido
   ```
5. Publique via **GitHub Pages** (Settings → Pages) para visualizar os exercícios de HTML/CSS/JS direto no navegador.

## ✅ Checklist geral de boas práticas

- [ ] Código indentado e legível
- [ ] Nomes de arquivos e pastas em minúsculo, sem espaços/acentos
- [ ] HTML validado (semântica correta, sem erros)
- [ ] Commits pequenos e com mensagens claras
- [ ] `README.md` de cada exercício lido antes de começar
