# Exercício 01 — Estrutura básica HTML5

**Objetivo:** compreender a estrutura mínima de um documento HTML5.

**Enunciado:**
Crie uma página `index.html` com uma pequena apresentação pessoal (nome fictício, curso, uma frase sobre você).

**Requisitos técnicos:**
- Declaração `<!DOCTYPE html>`
- Tags `<html lang="pt-br">`, `<head>` e `<body>`
- `<meta charset="UTF-8">` e `<title>` com o nome da página
- Ao menos um `<h1>` e dois `<p>`

**Arquivos esperados:**
```
01-estrutura-basica/
└── index.html
```

**Critérios de avaliação:**
- [ ] Estrutura HTML5 válida
- [ ] Uso correto de `<head>` e `<body>`
- [ ] Título da aba do navegador definido
