# Exercício 04 — Links e imagens

**Objetivo:** trabalhar navegação e mídia em HTML.

**Enunciado:**
Crie uma pequena "página de links úteis" com:
- Um link externo (ex.: para o site do seu Instituto Federal), abrindo em nova aba
- Um link interno (âncora) que leve para uma seção mais abaixo na mesma página
- Pelo menos duas imagens (podem ser de URLs externas), com atributo `alt` descritivo

**Requisitos técnicos:**
- `<a href="..." target="_blank" rel="noopener">`
- Âncora com `id` e link `<a href="#id">`
- `<img src="..." alt="...">`

**Arquivos esperados:**
```
04-links-imagens/
└── index.html
```

**Critérios de avaliação:**
- [ ] Link externo funcional e seguro (`rel="noopener"`)
- [ ] Âncora interna funcionando
- [ ] Imagens com `alt` descritivo (acessibilidade)
