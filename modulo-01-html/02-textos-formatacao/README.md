# Exercício 02 — Textos e formatação

**Objetivo:** usar corretamente as tags de texto e ênfase.

**Enunciado:**
Crie uma página com um pequeno artigo (pode ser sobre um assunto de sua escolha) usando títulos hierárquicos e formatação de texto.

**Requisitos técnicos:**
- Use `<h1>` até `<h3>` de forma hierárquica (sem pular níveis)
- Use `<strong>`, `<em>` e `<blockquote>` pelo menos uma vez cada
- Use `<hr>` para separar seções
- Parágrafos com `<p>`

**Arquivos esperados:**
```
02-textos-formatacao/
└── index.html
```

**Critérios de avaliação:**
- [ ] Hierarquia de títulos correta
- [ ] Uso adequado de ênfase (negrito/itálico com significado semântico)
- [ ] Citação usando `<blockquote>`
