# Exercício 05 — Tabelas

**Objetivo:** estruturar dados tabulares corretamente.

**Enunciado:**
Crie uma tabela com o "Horário de aulas da semana" (dias da semana nas colunas, horários nas linhas).

**Requisitos técnicos:**
- `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
- Use `colspan` ou `rowspan` em pelo menos uma célula (ex.: intervalo do almoço)

**Arquivos esperados:**
```
05-tabelas/
└── index.html
```

**Critérios de avaliação:**
- [ ] Separação correta entre cabeçalho (`thead`) e corpo (`tbody`)
- [ ] Uso de `colspan`/`rowspan`
- [ ] Tabela semanticamente correta (sem tabelas usadas para layout)
