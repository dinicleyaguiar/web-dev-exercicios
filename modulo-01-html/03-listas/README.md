# Exercício 03 — Listas

**Objetivo:** trabalhar com listas ordenadas, não ordenadas e aninhadas.

**Enunciado:**
Monte uma página com:
1. Uma lista não ordenada de "Linguagens que quero aprender"
2. Uma lista ordenada com o "Passo a passo para criar uma página web"
3. Uma lista aninhada (lista dentro de item de lista) com um menu de restaurante dividido por categorias (entradas, pratos principais, sobremesas)

**Requisitos técnicos:**
- `<ul>`, `<ol>` e `<li>`
- Pelo menos uma lista aninhada

**Arquivos esperados:**
```
03-listas/
└── index.html
```

**Critérios de avaliação:**
- [ ] Uso correto de `<ul>` e `<ol>`
- [ ] Lista aninhada funcionando corretamente
- [ ] Conteúdo organizado e coerente
