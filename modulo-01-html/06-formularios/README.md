# Exercício 06 — Formulários

**Objetivo:** construir um formulário HTML funcional (sem envio real de dados).

**Enunciado:**
Crie um formulário de "Cadastro de aluno" com os campos: nome, e-mail, data de nascimento, curso (select) e uma caixa de mensagem.

**Requisitos técnicos:**
- `<form>`, `<label>` associado corretamente a cada `<input>` (via `for`/`id`)
- Tipos de input variados: `text`, `email`, `date`
- `<select>` com pelo menos 3 `<option>`
- `<textarea>`
- Um botão `<button type="submit">`
- Use o atributo `required` em pelo menos dois campos

**Arquivos esperados:**
```
06-formularios/
└── index.html
```

**Critérios de avaliação:**
- [ ] Todos os `label` associados corretamente aos campos
- [ ] Tipos de input adequados a cada dado
- [ ] Validação nativa com `required`
