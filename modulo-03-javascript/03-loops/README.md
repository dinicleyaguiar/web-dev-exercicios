# Exercício 03 — Loops

**Objetivo:** dominar `for`, `while` e iteração sobre arrays.

**Enunciado:**
1. Use um `for` para exibir a tabuada de um número escolhido (1 a 10).
2. Use um `while` para exibir apenas os números pares entre 1 e 50.
3. Crie um array de 5 nomes e percorra com `for...of`, exibindo cada nome no console.

**Requisitos técnicos:**
- `for`, `while` e `for...of` usados pelo menos uma vez cada
- Nenhum loop infinito (sempre com condição de parada clara)

**Arquivos esperados:**
```
03-loops/
├── index.html
└── script.js
```

**Critérios de avaliação:**
- [ ] Os três tipos de loop implementados corretamente
- [ ] Resultados corretos exibidos no console
- [ ] Código sem loops infinitos
