# Exercício 02 — Estruturas condicionais

**Objetivo:** aplicar `if/else` e `switch`.

**Enunciado:**
Crie uma função `classificarNota(nota)` que retorna "Aprovado", "Recuperação" ou "Reprovado" conforme a nota (0 a 10). Depois, crie uma função `diaDaSemana(numero)` usando `switch` que retorna o nome do dia (1 = Domingo, ..., 7 = Sábado).

**Requisitos técnicos:**
- Uso de `if/else if/else`
- Uso de `switch/case` com `default`
- Testar as funções com pelo menos 3 valores diferentes cada, exibindo no console

**Arquivos esperados:**
```
02-condicionais/
├── index.html
└── script.js
```

**Critérios de avaliação:**
- [ ] Lógica condicional correta em ambas as funções
- [ ] `switch` com `default` tratado
- [ ] Testes cobrindo casos de borda (ex.: nota exatamente 7, dia inválido)
