# Exercício 04 — Funções

**Objetivo:** criar funções reutilizáveis, com parâmetros, retorno e valores padrão.

**Enunciado:**
Crie uma "calculadora simples" com funções `somar(a, b)`, `subtrair(a, b)`, `multiplicar(a, b)` e `dividir(a, b)`. A função `dividir` deve tratar divisão por zero retornando uma mensagem de erro.

**Requisitos técnicos:**
- Funções declaradas com `function` e ao menos uma como arrow function
- Uso de parâmetro com valor padrão em pelo menos uma função
- Tratamento do caso de divisão por zero

**Arquivos esperados:**
```
04-funcoes/
├── index.html
└── script.js
```

**Critérios de avaliação:**
- [ ] As quatro operações implementadas corretamente
- [ ] Divisão por zero tratada sem quebrar o programa
- [ ] Pelo menos uma arrow function utilizada
