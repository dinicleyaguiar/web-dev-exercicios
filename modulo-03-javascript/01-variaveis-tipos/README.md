# Exercício 01 — Variáveis e tipos de dados

**Objetivo:** entender `let`, `const` e os tipos primitivos do JavaScript.

**Enunciado:**
Crie um `script.js` que declare variáveis com seus dados pessoais (nome, idade, altura, se é estudante ou não) e exiba tudo formatado no `console.log`.

**Requisitos técnicos:**
- Uso de `let` e `const` (nunca `var`)
- Pelo menos uma `string`, um `number` e um `boolean`
- Uso de template strings (` `` `) para formatar a saída
- Uso do operador `typeof` para exibir o tipo de cada variável

**Arquivos esperados:**
```
01-variaveis-tipos/
├── index.html
└── script.js
```

**Critérios de avaliação:**
- [ ] Variáveis com os tipos corretos
- [ ] Template strings usadas corretamente
- [ ] Saída legível no console
