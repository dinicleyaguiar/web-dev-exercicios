# Projeto Final — Landing Page Interativa

**Objetivo:** integrar tudo o que foi aprendido nos três módulos em um único projeto.

**Enunciado:**
Desenvolva uma landing page de um produto, evento ou portfólio pessoal (à sua escolha), contendo:
- Cabeçalho com menu de navegação (âncoras internas)
- Seção "Sobre" com texto formatado
- Seção de "cards" com flexbox (produtos, serviços ou projetos)
- Um formulário de contato com validação em JavaScript
- Layout responsivo (media query para telas menores)
- Um pequeno recurso interativo extra (ex.: menu que abre/fecha, contador, dark mode)

**Requisitos técnicos:**
- HTML semântico (`<header>`, `<main>`, `<section>`, `<footer>`)
- CSS organizado em arquivo externo
- JavaScript separado em arquivo externo, sem erros no console
- Repositório com `README.md` próprio explicando o projeto

**Arquivos esperados:**
```
projeto-final/
├── index.html
├── style.css
├── script.js
└── README.md
```

**Critérios de avaliação:**
- [ ] Todos os módulos (HTML, CSS, JS) aplicados de forma integrada
- [ ] Responsividade funcional
- [ ] Código organizado e comentado
- [ ] Publicado via GitHub Pages (link no README do projeto)
